# Credits

DuneBox stands on a decade of open AR sandbox work. Thank you to everyone below.

## Upstream projects

| Project | What DuneBox uses it for |
|---|---|
| [SARndbox](https://web.cs.ucdavis.edu/~okreylos/ResDev/SARndbox/) by Oliver Kreylos, UC Davis KeckCAVES | The original augmented reality sandbox, and the idea of projecting topography back onto sand |
| [Magic-Sand](https://github.com/thomwolf/Magic-Sand) by Thomas Wolf | The base of DuneBox (C++): projector calibration, contour rendering, animal games |
| [openFrameworks](https://openframeworks.cc/) | The C++ creative-coding toolkit DuneBox (C++) runs on |
| [ofxDatGui](https://github.com/braitsch/ofxDatGui) by Stephen Braitsch, [thomwolf fork](https://github.com/thomwolf/ofxDatGui) | The DuneBox (C++) settings panels |
| [ofxModal](https://github.com/braitsch/ofxModal) by Stephen Braitsch | Calibration prompts in DuneBox (C++) |
| [ofxCv](https://github.com/kylemcdonald/ofxCv) by Kyle McDonald | OpenCV bindings for calibration |
| [pygame](https://www.pygame.org/) | Rendering and input for sandcam (Python) |
| [websockets](https://websockets.readthedocs.io/) and [segno](https://segno.readthedocs.io/) | The sandcam web dashboard and its pairing QR code |
| [libfreenect](https://github.com/OpenKinect/libfreenect) and [PyKinect2](https://github.com/Kinect/PyKinect2) | Kinect v1 and v2 depth access |

## Ideas from the community

- [RiverWeyTrust/ARSandbox-Adds](https://github.com/RiverWeyTrust/ARSandbox-Adds): lava flows and snow effects
- [danigeos/sARndbox](https://github.com/danigeos/sARndbox): erosion and sedimentation
